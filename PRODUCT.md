# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Friends who want to open a private real-time card or tile table from a phone or desktop browser and share one persistent chip wallet.

## Product Purpose

“同桌” provides a single social game lobby with shared accounts, avatars, wallet chips, invitations, reconnectable rooms, records and rankings.

## Operating Context

Players enter from the common game portal, create a room or join by room code, play synchronously, and return remaining table chips to the shared wallet when leaving.

## Capabilities and Constraints

- Games currently include Texas Hold’em, slots, 血流红中 and classic 炸金花.
- 炸金花 supports 2–8 players, one configurable minimum bet, no practice mode, and no buy-in ceiling.
- A player brings their entire currently available wallet balance into a 炸金花 room.
- The “235 beats trips” rule is available and enabled by default.
- Server code is authoritative for cards, legal actions, timers, settlement and durable room recovery.
- Existing account, avatar, wallet, leaderboard, admin and deployment behavior must remain compatible.

## Brand Commitments

The product name is “同桌”. The existing cat logo, dark social-game interface, Chinese copy style and animal avatar catalog remain shared across games.

## Evidence on Hand

Production code, automated tests, the cat logo and player avatar assets are stored in this repository. No external claims or player testimonials are supplied.

## Product Principles

- One identity and wallet across every game.
- Private information is visible only to the entitled player.
- Every chip movement is server validated and conserved.
- Rooms survive ordinary disconnects and service restarts.
- Mobile play remains a first-class experience.
