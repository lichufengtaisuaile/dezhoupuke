# 同桌 · 局域网游戏平台

2–6 人无限注德州扑克 + 复古街机老虎机，浏览器加入，使用虚拟筹码。支持手机、电脑和电脑陪练。

## 开始玩

1. 在作为主机的 Windows 电脑上双击 `start.cmd`，保留运行窗口。
2. 打开窗口显示的本机地址，默认是 http://localhost:3210 。首页是房间大厅，可输入昵称选择现有牌桌，或点击“创建房间”设置盲注和初始筹码。
3. 将房间内的邀请链接发给同一个 Wi-Fi／局域网里的朋友。朋友用浏览器打开，输入昵称加入；也可以在大厅使用“房间号加入”。
4. 至少两位玩家入座后，房主点击“开始牌局”。也可以先添加电脑陪练。

第一次安装需要 Node.js 20 或更新版本，以及网络下载依赖。本机已安装依赖后，游戏过程无需连接互联网。默认端口被占用时，会自动选择后续可用端口，以启动窗口里的地址为准。

## 游戏行为

- 小盲注、大盲注及初始筹码在创建房间时选择。最多 6 个座位。
- 支持弃牌、过牌、跟注、下注、加注和全押，自动处理翻牌、转牌、河牌、边池和平局。
- 加注数字表示本轮累计下注总额，包含本轮已经投入的筹码。
- 每次行动有 30 秒；超时会自动过牌，不能过牌时弃牌。
- 每手结算后倒计时 5 秒自动开始下一手，房主可关闭“自动下一手”或手动提前发牌。在线且有筹码的玩家不足两人时暂停等待；电脑陪练用完筹码会自动补充。
- 发牌、翻牌、推筹码、收底池和向赢家派筹码均有动画，金额随变化滚动。断线重连不重播之前的动画，系统开启减少动态效果时停用动画。
- 公开赢家的顺子、同花、葫芦、四条、同花顺和皇家同花顺会触发不同强度的桌边礼花，等待发牌动画结束后播放，同一手只播放一次；未亮出的底牌不触发，主动亮牌后可以触发。
- 盘中显示自己的底牌和当前牌型，按已经发出的公共牌实时更新；结算展示赢家底牌、中文牌型、踢脚牌和最佳五张组合。
- 其余玩家全部弃牌时，赢家的底牌默认不公开，可在下一手开始前点击“亮牌给大家看”。主动亮牌会重新开始一次下一手倒计时，重复点击不会继续延长。
- 右上角可开启音效并调节音量，默认静音。发牌、翻牌、下注、全下、收筹码、派彩、轮到自己、最后 5 秒和互动各有音效；浏览器需要先有点击或按键才能播放，切到后台或断线会取消待播声音。
- 本手中途加入的玩家从下一手开始。筹码用完后，可在两手之间补充。
- 大厅实时显示房主、房间人数、盲注和开局状态，支持搜索及状态筛选；牌桌内点击“返回大厅”会离开当前座位。
- 牌桌使用独立游戏布局，房间设置、邀请、电脑玩家和自动下一手集中在顶部的设置抽屉。竖屏底部固定手牌提示和行动区，手机横屏将操作区移到牌桌右侧；加注按钮展开金额面板，结算摘要可点开完整底牌、牌型和最佳五张组合。
- 点击其他玩家头像打开专属送花菜单，收花人固定为该玩家。普通表情和“祝你好运”“我要验牌”“好牌！”“谢谢”等快捷语从桌边工具栏发送给全桌，与送花入口分开。所有同桌玩家同步看到动画，发送间隔为 1.2 秒。
- 表情在头像附近避开手牌和筹码；窄屏无空位时短暂显示在头像上，短语无空位时保留文字播报。
- “我要验牌”是互动短语，不会翻开任何隐藏底牌；表情和鲜花不会改变筹码或牌局结果。
- 刷新同一个页面可恢复座位。离线座位保留 90 秒，期间轮到该玩家时仍按超时规则行动。
- 房主离线或退出后，房主身份交给其他在线玩家。
- 每位玩家只收到自己的底牌；摊牌后公开参与比牌的底牌，弃牌底牌保持隐藏。
- 陪练分三档难度（设置抽屉里"添加电脑玩家"上方选择，座位名字旁有 易/普/难 徽标）：
  - **简单**：只看自己的两张底牌——对子或大牌加注，能过就过，跟注较松。
  - **正常**：翻牌前同简单但加注更少；翻牌后开始读公共牌——两对及以上主动价值下注，一对和听牌过牌跟注，弱牌基本弃牌、偶尔小额偷池。
  - **困难**：在正常基础上讲底池赔率（牌越差要求赔率越低）、后位会偷盲偷池、听牌优先半诈唬、强牌在转牌河牌持续下注施压。
  - 陪练仅使用自己的底牌、公共牌及桌面公开的下注信息，不会看到其他玩家的暗牌；真人桌和练习桌都生效。

## 连接问题

朋友应使用主机的局域网地址，不能使用 `localhost`。连接同一路由器，且避免路由器的访客网络或设备隔离。

如果 Windows 首次显示网络访问提示，需要允许 Node.js 在当前可信网络上接受连接。公司网络也可能由管理员限制设备之间的访问。

游戏使用本地账号（昵称 + 密码）登录，密码以加盐哈希存储；未登录只能浏览大厅。每个账号有一个钱包：注册赠送 10,000 筹码，入座时从钱包带入，离桌自动退回，每一笔记入筹码流水（数据库 `data/dezhou.db`）。筹码不足时可领取每日补助（每天一次，总资产低于 2,000 可领 2,000）。也可以创建练习桌，练习桌使用免费练习筹码，不进出钱包、不计入战绩和排行榜。游戏没有支付、充值或真实金钱功能。

## 老虎机

门户首页点"老虎机"进入 `/slot/`：红金复古街机拉霸，与德州扑克共享同一钱包筹码。赔付表：777=50×、三钻=30×、三铃=15×、三BAR=10×、三樱桃=8×、任意三同=6×、任意一对=2×。下注档位 50 / 100 / 200 / 500，也支持自定义下注（10 - 100,000 的整数）。

- **服务端开奖**：`POST /api/slot/spin` 用 Node crypto 随机源抽出三个符号并按赔付表派奖，客户端只负责用返回结果播放转轴动画，不能影响开奖与结算。
- **幂等结算**：每次按下开奖前端生成 `spinId`（crypto.randomUUID），服务端 `spins` 表以其为主键；断网重试或重复点击同一局时直接回放首次结果，不会重复扣钱。扣款（SLOT_BET）与派奖（SLOT_WIN，未中奖不派奖也就不写）在同一 SQLite 事务内完成并各留一笔带 `spin` 引用的流水。
- **战绩分开统计**：个人中心"老虎机"页签分页列出每次旋转（时间、下注、三个符号、派奖、净盈亏）；总览新增老虎机次数与净盈亏，"累计净盈亏"为德州净盈亏加老虎机净盈亏。总资产口径不变（余额 + 桌上筹码）。
- 筹码不足时回门户领取每日补助（统一补助逻辑，老虎机页只做提示）。

房间状态保存在主机内存中，同时把座位与桌上筹码快照写入数据库：服务重启后座位和筹码会恢复（进行中的那一手作废），正常关闭时筹码自动退回钱包。

## 常驻牌桌与 NPC

大厅里常驻两张系统桌（房间号 880101 / 880102，盲注 5/10，买入 500），每张桌由 4–5 位 NPC 坐满大部分座位，始终留 1–2 个空位，加入方式和普通房间完全一样（房间号加入或大厅点击）。NPC 是**有真实账号的电脑玩家**：

- 对外完全表现为真人：牌桌上没有任何"电脑/陪练"标记，行动有 0.8–2.6 秒的随机思考延迟，昵称无后缀。
- 与真人同一套经济规则：入座、补筹都从自己的钱包真实扣款（BRING_IN），输光了按正常规则领每日补助（同样限每日一次），桌上筹码随时可赢走。
- 财富与战绩**计入系统排行榜**和战绩统计，和你输赢是真实划转。
- NPC 分三档难度（约 2:5:3 混合），打法固定各有不同；管理员封禁某个 NPC 后它会被移出且不再回桌。
- 管理后台的用户列表会给 NPC 账号显示"NPC"角标（仅管理员可见），数据库 `accounts.npc` 列有标记。

不想让 NPC 桌出现（比如纯朋友局部署）可以设环境变量 `NPC_TABLES=0` 关闭；`NPC_TABLES=1` 只保留一张。

## 管理后台

设置环境变量 `DEZHOU_ADMIN_TOKEN` 后开放 `/admin/` 管理员后台（不设置则后台接口返回 503，普通功能不受影响）：

```sh
DEZHOU_ADMIN_TOKEN='换成长随机串' npm start
```

打开 `http://<主机>:<端口>/admin/`，输入同一令牌进入。所有后台接口走 `Authorization: Bearer <令牌>`，令牌比对用常量时间实现。能力：

- **用户列表**：按昵称搜索、分页，展示可用余额、桌上筹码、总资产（余额 + 桌上）、德州手数、老虎机次数、净盈亏、封禁状态。
- **调整资金**：输入带符号整数金额与原因（必填，≤100 字），正数加钱、负数扣钱；扣减超出余额会被拒绝。每笔调整在事务内先写 `admin_audit` 审计，再以 `ADMIN_ADJUST` 类型记一笔流水（引用 `audit-<id>`，与审计一一对应，便于对账）。
- **封禁 / 解封**：封禁立即踢下线——socket 断开、座位清理、桌上筹码按 `CASH_OUT` 退回钱包；对局中的玩家由引擎按"中途离开"降级处理（轮到行动时自动弃牌推进，未到轮时由既有超时路径弃牌，退款恰好一次）。被封禁账号登录返回 403、socket 握手与 REST 一律 401。解封后恢复正常。
- **审计日志**：后台底部倒序列出所有调整资金与封禁/解封操作（操作者、目标用户、明细、时间），支持加载更多。

令牌保存在页面 sessionStorage，关标签页即失效。后台仅供管理员使用，请给令牌足够长度与随机性，不要复用其他密码。

## Linux 公网部署

支持直接使用 Node.js 和 systemd 部署，无需 Docker，配置见 [deploy/README.md](deploy/README.md)。生产入口是 `deploy/serve.js`，固定监听指定端口，避免端口冲突时自动换端口。系统服务可在关闭 SSH 后继续运行，并配置开机启动和异常退出自动重启。

当前服务名为 `dezhou`，应用路径为 `/home/admin/dezhou-current`。可用 `sudo systemctl status dezhou` 查看状态，使用 `sudo journalctl -u dezhou -n 80` 查看日志。更新或重启会作废进行中的手牌并把座位筹码保留在座位上（正常关闭时直接退回钱包），应在无人对局时操作。

## 开发与验证

```sh
npm ci
npm test
npm start
```

服务端：Node.js、Express、Socket.IO。客户端：原生 HTML/CSS/JavaScript、Lucide 图标。

规则使用锁定版本的 `poker-ts` 驱动发牌与下注流程，配合 `pokersolver` 比牌。`engine.js` 将已发现的牌型、短筹码全押及边池问题集中修正，测试覆盖这些回归场景。所有动作由服务端验证；客户端不能决定牌面或结算结果。

程序使用服务器随机源洗牌。它面向朋友间娱乐，不是经过认证的博彩系统。
