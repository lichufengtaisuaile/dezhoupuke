# 同桌 · 局域网德州扑克

2–6 人无限注德州扑克，浏览器加入，使用虚拟筹码。支持手机、电脑和电脑陪练。

## 开始玩

1. 在作为主机的 Windows 电脑上双击 `start.cmd`，保留运行窗口。
2. 打开窗口显示的本机地址，默认是 http://localhost:3210 。首页是房间大厅，可输入昵称选择现有牌桌，或点击“创建房间”设置盲注和初始筹码。
3. 将房间内的邀请链接发给同一个 Wi-Fi／局域网里的朋友。朋友用浏览器打开，输入昵称加入；也可以在大厅使用“房间号加入”。
4. 至少两位玩家入座后，房主点击“开始牌局”。也可以先添加电脑陪练。

第一次安装需要 Node.js 20 或更新版本，以及网络下载依赖。本机已安装依赖后，游戏过程无需连接互联网。默认端口被占用时，会自动选择后续可用端口，以启动窗口里的地址为准。

## 游戏行为

- 小盲注、大盲注及初始筹码在创建房间时选择。最多 6 个座位。
- 支持弃牌、过牌、跟注、下注、加注和全押，自动处理翻牌、转牌、河牌、边池和平局。
- 加注数字表示本轮累计下注总额，包含本轮已经投入的筹码。
- 每次行动有 30 秒；超时会自动过牌，不能过牌时弃牌。
- 每手结算后倒计时 5 秒自动开始下一手，房主可关闭“自动下一手”或手动提前发牌。在线且有筹码的玩家不足两人时暂停等待；电脑陪练用完筹码会自动补充。
- 发牌、翻牌、推筹码、收底池和向赢家派筹码均有动画，金额随变化滚动。断线重连不重播之前的动画，系统开启减少动态效果时停用动画。
- 本手中途加入的玩家从下一手开始。筹码用完后，可在两手之间补充。
- 大厅实时显示房主、房间人数、盲注和开局状态，支持搜索及状态筛选；牌桌内点击“返回大厅”会离开当前座位。
- 桌边互动支持表情、“祝你好运”“我要验牌”“好牌！”“谢谢”等快捷语，以及向指定玩家送花。点击座位上的名字可选择互动对象，所有同桌玩家同步看到动画，发送间隔为 1.2 秒。
- “我要验牌”是互动短语，不会翻开任何隐藏底牌；表情和鲜花不会改变筹码或牌局结果。
- 刷新同一个页面可恢复座位。离线座位保留 90 秒，期间轮到该玩家时仍按超时规则行动。
- 房主离线或退出后，房主身份交给其他在线玩家。
- 每位玩家只收到自己的底牌；摊牌后公开参与比牌的底牌，弃牌底牌保持隐藏。
- 陪练仅使用自己的底牌、公共牌及下注信息，是简单的练习对手。

## 连接问题

朋友应使用主机的局域网地址，不能使用 `localhost`。连接同一路由器，且避免路由器的访客网络或设备隔离。

如果 Windows 首次显示网络访问提示，需要允许 Node.js 在当前可信网络上接受连接。公司网络也可能由管理员限制设备之间的访问。

这个版本用于可信局域网聚会，没有公网账号体系。异地联机还需要部署到可访问的服务器或安排专用网络，不建议直接把电脑端口转发到公网。

房间和筹码保存在主机内存中，关闭主机程序后清空。游戏没有支付、充值或真实金钱功能。

## 开发与验证

```sh
npm ci
npm test
npm start
```

服务端：Node.js、Express、Socket.IO。客户端：原生 HTML/CSS/JavaScript、Lucide 图标。

规则使用锁定版本的 `poker-ts` 驱动发牌与下注流程，配合 `pokersolver` 比牌。`engine.js` 将已发现的牌型、短筹码全押及边池问题集中修正，测试覆盖这些回归场景。所有动作由服务端验证；客户端不能决定牌面或结算结果。

程序使用服务器随机源洗牌。它面向朋友间娱乐，不是经过认证的博彩系统。
